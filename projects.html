Spatial Selection Bias in Broadband Data

MSc thesis
Ookla + RURA data→ Observation model→ Cross-fit calibration→ Corrected estimates

Compares Ookla's self-selected speed tests against RURA's full subscriber census, then models the probability a location enters the crowdsourced sample to correct for it. Thirty quarters of measurements, terrain, and technology mix pulled from 28 regulator PDFs feed an out-of-fold calibration step.

  • Python
  • Geospatial
  • AWS Terrain Tiles
  • PDF Extraction
  • Propensity Modeling

Real-Time Fraud Detection

Source
Kafka→ Spark Structured Streaming→ Random Forest→ Postgres + HDFS

An end-to-end pipeline that simulates live transaction traffic and scores it in-flight. Predictions split two ways: Postgres for a low-latency Streamlit dashboard, HDFS as a data lake for batch analytics and retraining.

  • scikit-learn
  • PostgreSQL

eCommerce Purchase Prediction

Source
HDFS→ Kafka (WebHDFS)→ Spark Streaming (MLlib)→ MySQL→ Django

A fully containerized clickstream pipeline that predicts whether a shopping session will end in a purchase while the session is still in flight, surfaced on a live dashboard. Built with a five-person team for AUCA's Big Data Essentials course.

  • Docker Compose
  • HDFS
  • Kafka
  • PySpark MLlib
  • MySQL
  • Django
